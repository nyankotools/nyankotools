# ローカルLLM共同開発者向けコンテキスト

NyankoTools の開発に、ローカルLLM（opencode + Ollama + Qwen3.6 35B-A3B）が共同開発者として参加するための文書集。

- 元になっているのは Claude Code 向けの `CLAUDE.md` と `.claude/docs/`。ここではローカルLLMが扱いやすいよう、短く・具体的に・パスとコマンド中心に書き直している。
- 内容が食い違った場合は、元ドキュメント（`CLAUDE.md` / `.claude/docs/`）と実コードが正。気づいたらユーザーに報告する。
- コンテキストを節約するため、**全ファイルを毎回読まない**。下の早見表で必要なものだけ読む。

## タスク別・読むファイル

| やること                        | 読むファイル                 |
| ------------------------------- | ---------------------------- |
| 何も分からない状態から始める    | 00 → 01                      |
| 新規ツールを追加する            | 00 → 01 → 02 → 06            |
| 「No.xxx を実装して」と言われた | 08 → 00 → 01 → 02 → 06       |
| 既存ツールを修正する            | 00 → 01 → 06（必要なら 02）  |
| レビューする（指摘のみ）        | 00 → 03 → 06                 |
| QA・テストする                  | 00 → 04 → 05                 |
| コマンドが動かない              | 05                           |
| 動作が不安定・出力が壊れる      | 07                           |
| 前の担当者の作業を引き継ぐ      | handoff.md（最初に読む）→ 01 |

## このフォルダについて

- `.opencode/` は opencode のプロジェクト設定ディレクトリでもある（将来 `opencode.json` や `agent/` を置く場合はここに同居する）。現時点では文書（Markdown）だけを置いている。
- opencode は、リポジトリ直下の `AGENTS.md` から `.opencode/README.md` へ誘導する。

## 更新のルール

- ルールや手順を変えたら、元ドキュメントと該当する `.opencode/` のファイルの両方を更新する。
- `handoff.md` は作業の区切りごとに書き換える。他のファイルは規約が変わったときだけ更新する。
- 参照実装のパスを書いた箇所は、ファイルを移動・削除したときに必ず直す。
