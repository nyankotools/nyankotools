# NyankoTools 仕様書

最終更新: 2026-09-23

このドキュメントは NyankoTools（`nyankotools.com`）というプロダクトの機能・非機能仕様をまとめたものです。開発時のコーディング規約・アーキテクチャ詳細は [`CLAUDE.md`](../CLAUDE.md) と [`.claude/docs/`](../.claude/docs/) を参照してください（このドキュメントはそれらを重複させず、プロダクト仕様の観点でまとめ直したものです）。

## 1. プロダクト概要

- **名称**: NyankoTools
- **URL**: https://nyankotools.com
- **概要**: 開発者・クリエイター向けの、ブラウザ完結型の小さなユーティリティツールを集めたコレクションサイト。テキスト/データ変換・計算・生成系ツールを、日本語圏の長尾検索キーワード（例:「JSON 整形 オンライン 無料」）からの流入を主な獲得チャネルとして提供する。
- **対象ユーザー**: プログラマー・エンジニア・デザイナー・ライター・学生など、日常的にちょっとした変換・計算・整形作業を必要とする個人。
- **提供形態**: 会員登録・ログイン不要。インストール不要。すべてのツールは単一の静的サイト内で完結。
- **収益化方針**: 将来的に広告掲載・アフィリエイトによる収益化を想定（現時点では未実装）。そのため SEO・レスポンシブ対応・多言語化を継続的な投資対象として扱う。詳細は [`.claude/docs/growth.md`](../.claude/docs/growth.md)。

## 2. コア制約（プロダクトの前提）

- **完全クライアントサイド処理**: すべてのツールはブラウザ内の JavaScript のみで動作し、ユーザーが入力したデータをサーバーに送信しない。バックエンド API・DB を持たない。これはプライバシー訴求とゼロホスティングコストを両立させるための恒久的な設計方針であり、将来的にも変更しない。
- **静的サイト**: Astro の `output: static` でビルドし、Cloudflare Workers の静的アセット配信としてホストする。SSR・サーバーランタイムは存在しない。
- **CSP**: `connect-src 'none'` を含む厳格な Content-Security-Policy を適用しており、外部への通信自体が仕組みとして遮断されている（`astro.config.mjs` 参照）。

## 3. 情報構造・ページ一覧

### 3.1 サイト共通UI

- **サイドバー**: 常設のナビゲーション。カテゴリ別にツールを一覧表示し、開閉状態を localStorage 等で保持する。
- **トップページ**（`/`, `/en/`）: 全ツールをカードグリッドで一覧表示。検索・カテゴリ絞り込み機能を持つ（`src/lib/home-filter.ts`）。
- **ロケール切り替え**: サイドバー/ヘッダーの言語スイッチャーからユーザーが明示的に切り替える（Accept-Language 等による自動リダイレクトは行わない）。

### 3.2 静的ページ

| パス                | 内容                                       |
| ------------------- | ------------------------------------------ |
| `/about`            | サイト運営者情報（個人運営、実名は非公開） |
| `/contact`          | お問い合わせ                               |
| `/faq`              | よくある質問                               |
| `/privacy-policy`   | プライバシーポリシー                       |
| `/terms-of-service` | 利用規約                                   |
| `/404`              | 404エラーページ                            |

各ページは `en/` 配下に英語版が対になって存在する。

### 3.3 ツールページ

各ツールは `/tools/<slug>/`（日本語）と `/en/tools/<slug>/`（英語）の2つのURLを持ち、SEO上インデックス対象の独立したページとして提供される。

## 5. 機能横断の仕様

- **言語**: 日本語（デフォルト、パスプレフィックスなし）・英語（`/en/` 配下）。将来的な多言語追加はロケールディレクトリを増やすだけで対応できる設計（[`.claude/docs/growth.md`](../.claude/docs/growth.md)）。
- **SEO**: ツールごとに個別の `title`/`description`、`<h1>` は1つのみ、関連ツールへの内部リンク、hreflang・canonical・OGP・JSON-LD・サイトマップを整備。
- **レスポンシブ**: モバイルファースト。375px前後の狭い画面幅でもレイアウト崩れ・意図しない横スクロールが発生しないこと。タップ領域は目安44px四方以上。
- **アクセシビリティ/UX**: 入力に対してリアルタイム（デバウンス等を用いつつ即時に近い形）で結果を更新するインタラクションを基本とする。エラー時は分かりやすいメッセージを表示する。
- **セキュリティ**: 厳格な CSP（`connect-src 'none'` 等）を適用。ユーザー入力を innerHTML 等で描画する箇所は XSS 対策（サニタイズ、例: `dompurify`）を行う。

## 6. 非機能要件

| 項目           | 方針                                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| ホスティング   | Cloudflare Workers（静的アセット配信）。サーバーランタイムなし                                                                     |
| パフォーマンス | Astro の既定でJSゼロ出力を維持し、ツールごとに必要な最小限のスクリプトのみ読み込む。リンクホバー時の prefetch でページ遷移を高速化 |
| ブラウザ対応   | モダンブラウザを想定。prefetch 非対応ブラウザ等でのグレースフルデグラデーションは許容                                              |
| データ保存     | サーバー側にユーザーデータを保存しない。ブラウザの localStorage 等は UI 状態保持（サイドバー開閉、テーマ等）の範囲でのみ使用       |
| テスト         | ツールロジック（`src/lib/tools/*.ts`）は Vitest による単体テスト、ブラウザ挙動は Playwright による E2E テストでカバー              |

## 7. 技術スタック（サマリ）

| レイヤー             | 技術                                                             |
| -------------------- | ---------------------------------------------------------------- |
| フレームワーク       | Astro（`output: static`）                                        |
| スタイリング         | Tailwind CSS v4                                                  |
| 言語                 | TypeScript                                                       |
| UIインタラクティブ層 | 素の DOM 操作（React/Vue/Svelte 等のアイランドは原則使用しない） |

| デプロイ             | Cloudflare Workers（`wrangler.jsonc`）                           |

## 8. スコープ外（現時点で対応しない事項）

- ユーザーアカウント・ログイン機能
- サーバーサイドでのデータ処理・保存・API提供
- ツール間でのデータ連携・保存履歴機能（ブラウザを閉じると状態は失われる想定）
- ネイティブアプリ / PWAオフライン対応（現時点では未計画）
- 日本語・英語以外の言語（将来的な拡張余地はあるが未着手）

本ドキュメントは主要な機能追加（新ツールカテゴリの新設、対応言語の追加など）があった際に更新する。個々のツール追加自体は「4. ツールカタログ」の表を更新すれば足り、本ドキュメント全体の見直しは不要。ツール数・一覧の正は常に `src/data/tools.ts` とする。
